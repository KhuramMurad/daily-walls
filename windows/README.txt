Daily Walls for Windows - 1.2.0-alpha.2

Extract this entire folder before running DailyWalls.exe. Keep _internal beside it.
Use DailyWallsCLI.exe for terminal commands. Python and MSYS2 are not required on
an end user's computer; they are build dependencies only.

This is an unsigned development preview, not a stable Windows release.
Data and logs: %LOCALAPPDATA%\DailyWalls
Do not move the folder after registering optional scheduled maintenance without
registering the task again using its new path.

See WINDOWS.md for setup, limitations, testing, and maintenance instructions.
